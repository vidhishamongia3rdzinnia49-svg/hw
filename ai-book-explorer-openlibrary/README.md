
AI Book Explorer

A colorful React + Vite project that combines:
• Groq AI recommendations
• Open Library search
• title extraction from AI text
• horizontal scrollable book strip
• detail modal
• prefetching for faster interactions

Setup

1. Run npm install
2. Add your Groq API key in .env
3. Run npm run dev

Topics Covered

• Rendering visual recommendation results from AI output
• Extracting book titles from recommendation text
• Fetching matched book data for recommended titles
• Displaying recommended books in a scrollable strip
• Opening detailed information with modal state
• Prefetching book details for faster interaction
• Loading and interaction feedback
• Final responsive UI polish
